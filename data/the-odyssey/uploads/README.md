# Uploads for The Odyssey

Put student data files here. Every CSV in this folder is loaded by the site, alongside the posts collected automatically.

Use **Add file > Upload files** on GitHub. A minute or two later the site shows the new posts.

Start from `templates/student-posts-template.csv` so the columns are recognised. Name each file for who collected it and what it covers, for example `maria_cast_tiktok.csv`.
